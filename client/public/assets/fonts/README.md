# Fonts

The game uses **Orbitron** (display), **Rajdhani** (HUD / UI) and **Inter** (body),
loaded from Google Fonts in `client/index.html`.

To self-host (offline events, LAN parties), put the `.woff2` files here and replace
the Google Fonts `<link>` with `@font-face` rules in `client/src/styles/global.css`.
